# Соглашения

Действующие правила проекта. Причины решений — в [decisions.md](decisions.md).

## Структура папок (план)

```text
├── index.html                # главная
├── ui-kit.html               # живая витрина дизайн-системы
├── docs/                     # документация (этот раздел)
├── scripts/                  # служебные скрипты (конвертация картинок в WebP и т. п.)
├── public/                   # файлы «как есть» (favicon, robots)
└── src/
    ├── partials/             # HTML-партиалы
    │   ├── components/       #   компоненты UI-кита (btn, field, product-card…)
    │   └── sections/         #   секции главной (header, products, footer…)
    ├── data/                 # демо-данные для партиалов (товары, категории…)
    ├── scss/
    │   ├── abstracts/        #   токены, функции, миксины (без вывода CSS)
    │   ├── base/             #   сброс, шрифты, типографика, :root-переменные, темы
    │   ├── layout/           #   контейнер, секция, сетки
    │   ├── components/       #   по файлу на BEM-блок компонента
    │   ├── sections/         #   по файлу на BEM-блок секции
    │   ├── main.scss         #   точка входа сайта
    │   └── ui-kit.scss       #   стили только для страницы витрины
    ├── js/
    │   ├── modules/          #   по модулю на поведение (tabs, slider, header…)
    │   ├── main.js           #   точка входа: находит компоненты и инициализирует
    │   └── ui-kit.js
    ├── assets/
    │   ├── fonts/            #   Geologica (woff2)
    │   ├── icons/            #   SVG-иконки → спрайт
    │   └── images/           #   готовые WebP
    └── images-src/           # оригиналы картинок из Figma (PNG/JPG), не попадают в сборку
```

## BEM

- Блок — `.product-card`, элемент — `.product-card__title`, модификатор — `.product-card--compact`, `.btn--size-sm`.
- Модификатор с значением — через `--ключ-значение`: `.field--style-solid`, `.field--size-lg`.
- Один блок — один SCSS-файл, одно имя файла: `components/_product-card.scss`.
- Блоки не задают себе внешние отступы и позицию — это делает родитель через свой элемент (`.products__item`) или миксы.
- Состояния — классы `is-*` (`is-active`, `is-open`, `is-disabled`), их ставит JS.
- Хуки для JS — атрибуты `data-*` (`data-tabs`, `data-slider`), а не классы оформления.

## SCSS

- Только модульный синтаксис: `@use` / `@forward`, без `@import`.
- Токены живут в CSS-переменных на `:root` (`base/_tokens.scss`) — их меняет тема (`base/_themes.scss`). SCSS-переменные и карты — только для того, что не может быть CSS-переменной (брейкпоинты, текстовые стили).
- Цвета в компонентах — только смысловые `--color-*` (`--color-text`, `--color-bg`, `--color-border`…). Палитру (`--grey-*`) напрямую не используем, иначе сломается тёмная тема. Исключение — акцентные `--accent-*` (лейблы, рейтинг).
- Скругления — `var(--radius)`, отступы — `var(--space-*)` и `var(--gap)`, ритм секций — `var(--rhythm-*)`.
- Текст: в компонентах `@include text(h4)`, в разметке без своего блока — класс `.text-h4`. Список стилей — `abstracts/_typography.scss`.
- Раскладка страницы: `.container` (контент 1696 + поля `--page-padding`) и `.section` (модификаторы `--space-2`, `--space-3`, `--alt`).
- Миксины: `media-up($bp)` / `media-down($bp)`, `text($style)` для текстовых стилей Figma, `visually-hidden`, `hover` (только на устройствах с hover).
- Числа из макета не пишем «голыми»: отступы, цвета, размеры шрифта — через токены. Исключение — уникальные размеры конкретного компонента.
- Единицы: `rem` для шрифтов и отступов (база 16 px), `px` для бордеров. Конвертация через функцию `rem()`.
- Порядок свойств — по смыслу (позиционирование → блочная модель → типографика → оформление → прочее); стайлинт настроим на этапе 0.

## JS

- ES-модули, без глобальных переменных и jQuery.
- Модуль = поведение: `tabs.js`, `slider.js`, `countdown.js`, `header.js`, `theme-switcher.js`.
- Каждый модуль экспортирует функцию `init…(root = document)`; `main.js` вызывает их по наличию `data-*` атрибутов.
- Без лишних зависимостей. Для слайдеров — решение в [decisions.md](decisions.md).

## HTML

- Семантика: `header`, `nav`, `main`, `section` с заголовком, `article` для карточек, `footer`.
- Доступность: `alt` у картинок, `aria-label` у кнопок-иконок, видимый фокус, табы и слайдеры — с клавиатуры.
- Картинки — `<img>` с `width`/`height`, `loading="lazy"` ниже первого экрана, `decoding="async"`.

## Картинки

- В сборку идут только WebP. Оригиналы из Figma — в `src/images-src/`, конвертация — скриптом `npm run images` (sharp).
- Для крупных картинок — две плотности (1x, 2x) через `srcset`.
- Иконки — SVG, собираются в спрайт; цвет — через `currentColor`.

## Git

- Коммиты по [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/): тип и область на английском, описание на русском.
  Пример: `feat(ui-kit): добавить кнопки и лейблы`.
- Области: `ui-kit`, `home`, `scss`, `js`, `build`, `docs`, `assets`.
- Один коммит — один законченный шаг. После каждого этапа — обновление [PLAN.md](PLAN.md) и статусов в [components.md](components.md).
