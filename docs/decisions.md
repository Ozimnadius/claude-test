## Предложения (приняты 2026-11-25, оставлены для истории)

| #   | Вопрос                                             | Предложение                                                                                                                                                                           | Альтернатива                                                                                         |
| --- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| П1  | Как собирать HTML из частей                        | `vite-plugin-handlebars`: партиалы с параметрами + данные из JSON. Карточки товаров и категорий рендерятся циклом из демо-данных, один партиал используется и в UI-ките, и на главной | `posthtml-include` — проще, но без циклов и параметров; или чистый HTML с копированием               |
| П2  | Слайдеры (бренды, видеоотзывы, мобильные карусели) | Swiper (стандарт, доступность и свайпы из коробки, ~40 КБ)                                                                                                                            | Свой лёгкий слайдер на CSS `scroll-snap` + JS для стрелок — меньше веса, больше работы               |
| П3  | Шрифт                                              | Локально, woff2 из пакета `@fontsource-variable/geologica`                                                                                                                            | Подключение с Google Fonts — проще, но внешний запрос                                                |
| П4  | Конвертация в WebP                                 | Скрипт на `sharp` (`npm run images`): оригиналы в `src/images-src/`, результат в `src/assets/images/`                                                                                 | Плагин Vite, конвертирующий при сборке — меньше ручных шагов, но медленнее сборка и сложнее контроль |
| П5  | Иконки                                             | SVG-спрайт (`vite-plugin-svg-icons` или свой скрипт) + `<svg><use>`                                                                                                                   | Инлайн SVG в партиалах                                                                               |
| П6  | Линтеры                                            | Stylelint (порядок свойств, BEM-паттерн) + Prettier                                                                                                                                   | Без линтеров                                                                                         |
