# Дизайн-токены

Источник — переменные Figma (`get_variable_defs`) и панель текстовых стилей (фрейм `316:395411`).
Значения сняты 2026-11-25. В коде токены станут CSS-переменными (`--color-…`, `--font-…`) с SCSS-обёртками — см. [conventions.md](conventions.md).

## Темы (режимы переменных)

В Figma часть переменных имеет несколько режимов. Найдено:

| Переменная                   | Главная (`26:278`) | Типографика (`164:65301`) | Base Elements / Кнопки |
| ---------------------------- | ------------------ | ------------------------- | ---------------------- |
| `Main Color`                 | `#3153d3` синий    | `#d7252c` красный         | `#d7252c` красный      |
| `Radius`                     | `8`                | `6`                       | `0`                    |
| `Theme Width` (боковые поля) | `112`              | `210`                     | `112`                  |

Вывод: основной цвет, скругление и ширина полей — параметры темы. Делаем их CSS-переменными на `:root` и переключаемыми через атрибут (например, `data-theme`). **Тема по умолчанию для главной — синяя, скругление 8, поля 112** (как в макете главной). Красная тема — проверочная: если UI-кит корректно перекрашивается сменой переменных, система собрана правильно.

## Типографика

Шрифт — **Geologica** (переменная `Name`). Начертания: Regular 400, Medium 500 (переменная `Style`), SemiBold 600.
Межстрочный интервал в названиях стилей: «142» = 1.42, «110» = 1.1, «120» = 1.2, «132» = 1.32; если указаны пиксели (21, 22, 16, 20, 23, 32) — это px.

| Группа  | Стиль           | Размер / интервал    | Начертание              |
| ------- | --------------- | -------------------- | ----------------------- |
| Display | Hero 42-110     | 42 / 1.1             | Medium 500              |
| Heading | H1 32-142       | 32 / 1.42            | Medium 500              |
|         | H2 28-142       | 28 / 1.42            | Medium 500              |
|         | H3 24-142       | 24 / 1.42            | Medium 500              |
|         | H4 20-142       | 20 / 1.42            | Medium 500              |
|         | H5 18-142       | 18 / 1.42            | Medium 500              |
|         | H6 16-142       | 16 / 1.42            | Medium 500              |
| Body    | 16 Bold-142     | 16 / 20px            | SemiBold 600            |
|         | 16-142          | 16 / 1.42            | Regular 400             |
|         | 15-142          | 15 / 1.42            | Regular 400             |
|         | 14-142          | 14 / 1.2             | Regular 400             |
|         | 13-142          | 13 / 1.42            | Regular 400             |
|         | 12-142          | 12 / 1.42            | Regular 400             |
|         | 18-132          | 18 / 1.32            | Regular 400 (уточнить)  |
| Button  | 14-21           | 14 / 21px            | Regular 400             |
|         | 15-22           | 15 / 22px            | Regular 400             |
|         | 15 Bold-22      | 15 / 22px            | SemiBold 600            |
|         | 16-16           | 16 / 16px            | Regular 400             |
| Price   | 18 Bold-142     | 18 / 1.42            | SemiBold 600            |
|         | 16 Bold-142     | 16 / 1.42            | SemiBold 600 (уточнить) |
|         | 24 Bold-142     | 24 / 32px            | SemiBold 600 (уточнить) |
| Label   | Uppercase 10-23 | 10 / 23px, ПРОПИСНЫЕ | Regular 400             |

«Уточнить» — стиль виден на скриншоте панели, но его переменная не попала в выгрузку; начертание проверим через `get_design_context` на конкретном элементе.

Шкала размеров (`Typography/Size …`): 16, 18, 20, 24, 28, 32, 42.

| Токен                              | Значение                    | Назначение                           |
| ---------------------------------- | --------------------------- | ------------------------------------ |
| Indents/4…18                       | 4, 6, 8, 10, 12, 14, 16, 18 | внутренние отступы компонентов       |
| Gap                                | 24                          | шаг сетки карточек                   |
| Paddings/Vertical Rythm 1          | 80                          | вертикальный отступ секции (большой) |
| Paddings/Vertical Rythm 2          | 60                          | вертикальный отступ (средний)        |
| Paddings/Vertical Rythm 3          | 35                          | вертикальный отступ (малый)          |
| Paddings/Main Padding, Theme Width | 112                         | боковые поля контейнера на 1920      |

Контейнер на 1920: `1920 − 2 × 112 = 1696 px` (так и назван фрейм главной: «Контейнер 1696»).

## Скругления

`Radius` — один токен темы: 8 (главная), 6 или 0 (другие режимы). Все скругления компонентов берём от него, чтобы тема меняла их разом.
