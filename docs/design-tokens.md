## Темы (режимы переменных)

В Figma часть переменных имеет несколько режимов. Найдено:

| Переменная                   | Главная (`26:278`) | Типографика (`164:65301`) | Base Elements / Кнопки |
| ---------------------------- | ------------------ | ------------------------- | ---------------------- |
| `Main Color`                 | `#3153d3` синий    | `#d7252c` красный         | `#d7252c` красный      |
| `Radius`                     | `8`                | `6`                       | `0`                    |
| `Theme Width` (боковые поля) | `112`              | `210`                     | `112`                  |

Вывод: основной цвет, скругление и ширина полей — параметры темы. **По умолчанию — синий бренд, скругление 8, поля 112** (как в макете главной).

В коде две независимые оси, атрибуты ставятся на `<html>`:

| Атрибут      | Значения                       | Что меняет                                      |
| ------------ | ------------------------------ | ----------------------------------------------- |
| `data-brand` | `blue` (по умолчанию), `red`   | `--brand-main`, `--brand-main-dark`, `--radius` |
| `data-theme` | `light` (по умолчанию), `dark` | смысловые цвета `--color-*`, `color-scheme`     |

Красный бренд: `#d7252c`, скругление 0 (режим Base Elements). Переключатель — только в UI-ките.

## Отступы

| Токен                                        | Значение                    | Назначение                                                                                 |
| -------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------ |
| Indents/4…18 → `--space-4…18`                | 4, 6, 8, 10, 12, 14, 16, 18 | внутренние отступы компонентов                                                             |
| Gap → `--gap`                                | 24                          | шаг сетки карточек (во фрейме Components этот токен даёт 6 — разберёмся на этапе карточек) |
| Vertical Rythm 1 → `--rhythm-1`              | 80                          | вертикальный отступ секции (большой)                                                       |
| Vertical Rythm 2 → `--rhythm-2`              | 60                          | вертикальный отступ (средний)                                                              |
| Vertical Rythm 3 → `--rhythm-3`              | 35                          | вертикальный отступ (малый)                                                                |
| Main Padding, Theme Width → `--page-padding` | 112                         | боковые поля контейнера на 1920                                                            |

Контейнер на 1920: `1920 − 2 × 112 = 1696 px` (так и назван фрейм главной: «Контейнер 1696»). В коде — `.container`, ширина контента `--container-width`. Поля на узких экранах временно 32 px (≤ 1200) и 16 px (≤ 768), уточним на этапе 5.

## Скругления

`Radius` → `--radius` — один токен темы: 8 (синий бренд), 0 (красный). Все скругления компонентов берём от него, чтобы тема меняла их разом.
