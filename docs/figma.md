## Особенности макета, которые надо учитывать

1. **Переменные с режимами (темами).** Одни и те же переменные дают разные значения в разных фреймах: на главной основной цвет `#3153d3` (синий), скругление 8, поля 112; во фреймах дизайн-системы — `#d7252c` (красный), скругление 0 или 6, поля 210. Значит, тема переключаемая, и вёрстку делаем на CSS-переменных.
2. **Страница «Кнопки» (`74:27675`) выбивается из системы:** другой шрифт (похож на Inter) и цветные кнопки в духе Bootstrap (Success, Info, Warning…). Скорее всего, это стили для контента из визуального редактора, а не кнопки интерфейса. Нужно подтверждение — см. [decisions.md](decisions.md).
3. **В шапке есть иконки солнца и луны** — переключатель светлой/тёмной темы. Тёмной темы в переданных фреймах нет.
4. Макет — шаблон (похоже на решения Аспро: тексты «Аспро: Премьер», «Маркет PRO»). Тексты и картинки — демо-контент.
